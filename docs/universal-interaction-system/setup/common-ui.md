# Common UI
This plugin works independently and does not require any additional plugins.

Optional integration is available with the **[Midofey Systems Common UI](/common-ui)** plugin, which adds enhanced UI functionality such as advanced rich-text support, gamepad icon display, and additional UI styling features.

If the Midofey Systems Common UI plugin is installed, these extended UI features will be used automatically. Otherwise, the plugin will use its built-in fallback UI to ensure full functionality without any additional dependencies.
