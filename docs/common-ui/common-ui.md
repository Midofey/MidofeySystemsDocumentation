# Common UI

The **Common UI** plugin defines shared UI foundations and conventions used across Midofey Systems.

It provides a set of base UI elements, styles, and utilities that other Midofey Systems plugins can build upon to ensure a consistent look and feel across all UI components.

You can change the styling and behavior of the Common UI elements to fit your project's needs, while still maintaining compatibility with the other Midofey Systems plugins.

:::note
The Common UI plugin is a free plugin you can get at the Fab Marketplace: [Midofey Systems Common UI](https://www.fab.com/listings/f5dff658-e019-4e88-ae87-ae80f83fc627).
:::
