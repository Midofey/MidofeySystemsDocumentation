# Welcome
Welcome to the documentation for the **Midofey Systems** plugins! This collection of plugins provides a framework for creating dynamic, system-driven gameplay elements in Unreal Engine projects.

The core plugins include:
- [**Common UI**](/common-ui): Shared UI foundations and conventions used across Midofey Systems.
- [**Notification System**](/notification-system): A centralized mechanism for delivering gameplay-relevant messages to the player.
- [**Universal Interaction System**](/universal-interaction-system): A standardized approach for player interactions with gameplay objects.
- [**Quest System**](/quest-system): A graph based framework for defining, tracking, and progressing gameplay objectives/missions.

Each plugin is designed to be modular and extensible, allowing you to pick and choose the systems that best fit your projects needs. The documentation provides detailed information on the design, integration, and usage of each plugin, along with visual aids to help you get started.

Whether you are building a complex RPG with branching quests or a simple action game with contextual interactions, the Midofey Systems plugins offer a solid foundation for creating engaging gameplay experiences. Dive into the documentation to learn more about each system and how they can work together to enhance your project!

You can purchase all of the Midofey Systems plugins on the Fab Marketplace: [Midofey Systems Fab](https://www.fab.com/sellers/Midofey%20Systems). Each plugin is available separately. 

**Happy developing!**
